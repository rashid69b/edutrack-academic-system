# Project Statement

## Project title
EduTrack – Student Academic Management System

## Problem
Academic course registration involves students, courses, credit limits, available seats, marks and grades. A small command-line system can demonstrate how these operations can be organized using object-oriented programming.

## Objective
Develop a Java CLI application that models students, courses and enrollments while applying encapsulation, abstraction, inheritance, polymorphism, interfaces, exception handling, collections and file handling.

## Main users
- Student
- Faculty member
- Academic administrator

## Functional scope
1. Register students.
2. Add theory and laboratory courses.
3. Display the course catalogue.
4. Enroll students while validating capacity, duplicate registration and credit limits.
5. Record marks.
6. Calculate letter grades and CGPA.
7. Generate a transcript.
8. Display simple analytics.
9. Save and reload records from text files.

## OOP concepts demonstrated
- Encapsulation: private fields with controlled methods.
- Abstraction: abstract Course class.
- Inheritance: LectureCourse and LaboratoryCourse extend Course.
- Polymorphism: course-specific workload calculation.
- Interface: Repository contract.
- Exception handling: domain-specific checked exceptions.
